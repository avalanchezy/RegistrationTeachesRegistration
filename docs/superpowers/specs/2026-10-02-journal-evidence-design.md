# Journal evidence, second iteration

User intent: continue substantive work toward a KBS/MedIA journal extension. Real data are on another machine; preserve existing preprocessing interfaces and push the research branch. No real-data performance or publication readiness can be inferred from software tests.

## Decision

Three options were considered: enlarge the network, add verification thresholds, or expose the two central hypotheses to independent measurement. Choose the third. More capacity cannot establish novelty; more uncalibrated gates cannot establish correctness.

1. **Verification audit.** Run the existing verifier on manual development or locked evaluation records with reference transform and labels removed from its input. Only after it returns, compare the accepted transform with the saved reference on fixed anchors. Match the exporter’s complete-case jaw acceptance, then aggregate failures by patient. Report rejection coverage, false acceptance, and a one-sided exact binomial upper confidence bound. Distinguish exploratory development evidence from a frozen-policy audit. A checkpoint selected on validation patients is not an independent certification cohort. Save the full gate/run/checkpoint/data provenance, and never optimize thresholds on a locked audit inside this tool.
2. **Convergence experiment.** Generate repeatable physical SE(3) perturbations around the reference for diagnosis only, shared across checkpoints. Report initial/final fixed-anchor displacement, energy change, capture rate, and deterioration by rotation/translation magnitude, with patient aggregation. Dense and implicit heads use the same runner and budget. These oracle-centered starts are not a deployment result. Preserve improper reference parity; fail numerical runs without deleting them.
3. **Critical repairs.** Reproduce and fix any concrete physical geometry, leakage, or scoring defects found by the independent code audit. Add regression tests before changes.

The new audit must be useful when it finds no accepted patients: risk upper bound is 1, and small samples cannot demonstrate a small false-acceptance risk. Repeated jaws, scans, and starts do not increase independent sample size. Fixed-anchor displacement is not anatomical landmark TRE. Same-teacher holdout remains self-consistency even when its correlation with independent references is measured.

Operational resumption of long exports is useful but secondary to these scientific checks. Avoid a new model family or a claim of formal deployment safety without data and appropriate sampling assumptions.

## Verification and delivery

Meaningful tests include GT stripping, patient/case aggregation, wrong parity at zero coplanar displacement, exact confidence bound edge cases, frozen-cohort provenance guards, deterministic perturbations across input ordering, physical centroid invariance, and an analytic field showing actual convergence. Use a fresh synthetic checkpoint to exercise both new CLIs. Run the full suite and source-only audit, request independent review, update Chinese experiment instructions and evidence ledger, then push the already authorized branch.

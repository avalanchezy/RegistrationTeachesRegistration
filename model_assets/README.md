# Model assets

This directory is intentionally empty in the public source release.

The submitted system expects the files listed in
`configs/submission/model_assets.sha256`. The neural checkpoints and tree
models are learned artifacts. The two template-bank files also contain sampled
geometry derived from organizer-provided STSR data, so they are not
redistributed without explicit dataset permission.

Registered challenge participants can reproduce the assets from the official
Task 2 data by following `docs/REPRODUCE.md`. Team members may instead place the
private, integrity-checked submission asset bundle here. Do not commit those
files to GitHub.
